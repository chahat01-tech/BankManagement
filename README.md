# Bank Management
The Bank Management System is a C-based project that allows users to create, search, update, and delete bank accounts. It also provides deposit, withdrawal, and balance-checking facilities using file handling and structures.

# Features of the Project
The project provides the following features:
Create N ew Account: Allows users to create a new bank account by entering account number, name, age, phone number, and initial deposit.
Display All Accounts: Displays the details of all registered accounts.
Search Account: Finds an account using its account number.
Deposit Money: Adds money to an existing account and updates the balance.
Withdraw Money: Allows users to withdraw money if sufficient balance is available.
Check Balance: Displays the available balance of a particular account.
Modify Account Details: Updates the customer's name, age, and phone number.
Delete Account: Removes an existing account from the records.
Exit: Terminates the application.
# Concepts of C Programming Used
- Header Files: stdio.h, stdlib.h, and string.h are used for input/output, file operations, and string handling.
- Structures: struct Account stores customer details such as account number, name, age, phone number, and balance.
- Functions: Separate functions are created to perform banking operations like deposit, withdrawal, search, and account creation.
- File Handling: Used to save, read, update, and delete account records permanently.
- Pointers: File pointers are used to access and manage files.
- Conditional Statements: if-else and switch are used for decision-making and selecting menu operations.
- Loops: while and do-while loops are used to repeat menu operations and process account records.
- Variables and Data Types: int, char, and float store account details and transaction amounts.
- Input Validation: Checks user input, duplicate account numbers, and invalid transaction amounts.
# Working of the Project
The project follows these steps:
1. Start the Program: Displays the main menu with available banking operations.
2. Select an Option: The user chooses an operation from the menu.
3. Create Account: Enters customer details and saves them in bank.dat.
4. View or Search Account: Displays all accounts or searches for a specific account number.
5. Perform Transactions: Deposits or withdraws money and updates the account balance.
6. Check Balance: Displays the current balance of the selected account.
7. Modify Account: Updates the existing customer's personal details.
8. Delete Account: Removes an account record using a temporary file.
9. Exit: The program terminates when the user selects the exit option.
